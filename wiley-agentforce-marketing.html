✶ Built for Wiley · 2026

From campaign brief to activated campaign in minutes.

You already use Claude to write briefs. Here is how Agentforce connects the rest of the process.

The Workflow

Conceive, Approve, Build, Activate.

This is the process the team walked through in the workshop. Each step can be handled by an agent.

1
Conceive
Draft, segment, and pull context automatically.
A marketer prompts Claude with a campaign objective. The agent drafts a brief, identifies the target segment, and pulls in relevant account and company data.
2
Approve
Human review without the back-and-forth.
The draft brief surfaces in Slack or email for human review. One click to approve, edit, or send back. No dev work required.
3
Build
Campaign Creation Agent builds the full journey.
Once approved, the Campaign Creation Agent builds emails, SMS, audience segments, and applies Einstein STO automatically inside Flow.
4
Activate
Live campaign, with real-time decisioning.
Campaign goes live. Analytics Agent tracks performance. Journey Decisioning routes contacts in real time based on behaviour.

✶ Implementation Guide · 2026

Start small. Prove fast. Then scale.

A practical path for Wiley's marketing team to get the first agent live.

Implementation Path

Three phases, three quick wins.

Phase 1: Crawl

One campaign type. Measured baseline.

Activate Campaign Creation Agent on one campaign type using your existing MCAE licence. Measure time-to-launch vs. current baseline.

Phase 2: Walk

Nurture journeys and ABM content.

Add Conversational Email to your top-performing nurture journey. Connect ABM content generation to your existing brief process in Claude.

Phase 3: Run

B2B pages, Data Cloud, custom agents.

Deploy Piper on high-intent B2B pages. Connect Data Cloud for cross-cloud personalisation. Build custom agents for your specific MIDB data layer.
