✦ The proposal

Data Cloud + Marketing Cloud Next

Not a rip-and-replace. CitySprint already has Snowflake, Data Cloud credits, and Marketing Cloud. This is about activating what's already there — and closing the gaps.

Data Cloud

Connect Snowflake, CityTrack, and CRM into one customer view

CitySprint has already built a Snowflake data warehouse. Data Cloud connects directly to it — no copying, no moving data — and joins it to CRM and CityTrack operational records to create a single customer profile marketing and sales can actually use.

🔗
Snowflake zero-copy integration
CitySprint's existing Snowflake investment connects directly to Data Cloud without duplicating or moving data. What you've already built becomes activatable for the first time.
🎯
Churn risk scoring
Identifies accounts where booking frequency is dropping or service complaints are spiking — before they cancel. Triggers retention journeys automatically.
📊
Closed-loop attribution
Connects paid media clicks through to won accounts in Salesforce. Fixes the 75% "Direct" problem — marketing can finally show what spend is generating revenue.
👥
Segmentation on real behaviour
Segments built on actual delivery frequency, sector, and service type — not just CRM fields. Enables true ABM and personalised campaign targeting.
💡
CitySprint already has Data Cloud credits
Data Cloud was included via the Foundations agreement. The cost here is implementation and activation — not the licence. Same for the ~30k Agentforce conversation credits already in the contract.
Marketing Cloud Next

Replace manual processes with campaigns that run themselves

MC Next sits on top of the Data Cloud layer. It's an in-place upgrade from the MCAE Advanced licence CitySprint is already on — no migration required.

Journeys

Automated, trigger-based campaigns

DSU onboarding, lapsed customer win-back, and same-day to next-day upsell journeys — all running on behavioural triggers from Data Cloud. No manual list exports.

Attribution

MC Intelligence — already active

Attribution and spend optimisation across Google, Meta, and LinkedIn. Directly answers the requirement to prove ROI on paid media. Available now — needs connecting to Data Cloud to close the loop.

AI

Agentforce Campaigns

AI-generated audience segments and campaign briefs. A lean marketing team can run more campaigns without more headcount — Jen's stated goal when she came in.

"Marketing was previously semi-detached. Jen's goal is joined-up, data-driven sales and marketing working hand-in-glove on revenue growth."
